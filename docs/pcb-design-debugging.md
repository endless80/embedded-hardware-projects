# PCB 设计与调试记录

## 设计范围

- 51 单片机核心板
- USB 2.0 拓展坞
- STM32 单片机开发板

## 设计流程

1. 需求分析与器件选型
2. 原理图绘制和网络检查
3. PCB 布局、布线与铺铜
4. 设计规则检查和打样文件导出
5. 元器件焊接与基础电性能测试
6. 板级联调和问题整改

## 典型问题与处理

### 复位不稳

- 检查复位 RC 参数和上电时序
- 优化复位信号走线
- 加强电源去耦

### 串口乱码

- 核对波特率、时钟源和共地连接
- 检查串口线缆与接口焊接
- 使用串口调试助手和示波器复核信号

### 电源纹波

- 检查电源输入和负载电流
- 优化去耦电容布局，缩短高频回流路径
- 增加必要的输入输出滤波

## 使用仪器

- 万用表：通断、供电、短路和基础电平检查
- 示波器：电源纹波、晶振、复位和串口波形观察
