# 充电桩系统设计说明

## 项目目标

基于 STM32F103 设计充电桩远程控制系统，将充电流程、传感器采集、显示交互和上位机通信整合为完整系统，而不是单一外设示例。

## 系统组成

- 主控：STM32F103ZET6
- 采样：ADC 电压采集、DHT11 温湿度、MQ-2 与光照检测
- 人机交互：OLED 菜单、按键、蜂鸣器
- 控制输出：继电器、直流电机、步进电机
- 通信：UART、RS485、ESP8266 Wi-Fi、NRF24L01
- 存储：AT24C02、W25Q64 与 SD 卡
- 可靠性：看门狗、掉电保护、异常状态处理

## 充电状态机

系统包含 5 种状态：

1. 待机
2. 握手
3. 充电
4. 故障
5. 结束

各状态负责独立的任务调度、显示内容和输出控制，异常时可进入故障状态并安全断开继电器。

## 软件结构

- `User/main.c`：任务调度和充电状态机
- `Hardware/sensor/`：ADC、DHT11、MQ-2、光敏和红外驱动
- `Hardware/communication/`：UART、RS485、ESP8266、NRF24L01
- `Hardware/storage/`：EEPROM、SPI Flash 和 SD 卡
- `Hardware/display/`：LCD 与触摸驱动
- `Hardware/control/`：继电器、电机和指示灯

## 串口与上位机

UART 用于调试输出、上位机数据上报、参数配置和远程控制。协议层将数据采集、充电状态和故障信息封装后发送，上位机可据此监控充电流程。
