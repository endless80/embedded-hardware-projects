# 基于 FPGA 的北斗时间解析与显示系统

## 项目范围

使用 Verilog HDL 完成 UART 接收、NMEA/GNRMC 时间帧解析、UTC+8 换算和时间显示。当前版本未完成 PPS 秒脉冲校准，因此不应作为完整高精度授时系统宣传。

## 已完成内容

- 50 MHz 系统时钟下的 UART 接收模块
- 9600 bit/s 波特率计数与采样时刻校正
- 起始位、8 位数据位和停止位处理
- GNRMC 帧头识别、字段提取和异或校验
- 时间字段 BCD 转换与 UTC+8 换算
- 时间显示驱动
- ModelSim 正常帧和异常帧验证

## 非整数分频问题

50 MHz 时钟按 9600 bit/s 计算：

`50,000,000 / 9,600 = 5,208.33`

因此不能直接使用固定整数分频。工程采用计数分频与采样时刻校正方式处理累计误差。

## 当前限制

- PPS 秒脉冲输出和硬件校准尚未完成
- 当前定位为时间解析与显示系统，不是完整授时终端
- 后续可扩展 PPS 采样、本地时钟保持和误差统计
